# World Population Dashboard

## Overview
This project presents a dashboard created using Tableau to analyze world population data. The dashboard visualizes population trends, growth rates, and demographic insights.

## Data Source
The data used in this dashboard is sourced from  CSV file. The dataset includes information on population figures from various countries over the years.

## Files
- `data/world_population_data.csv`: The dataset used for analysis.
- `dashboard/world_population_dashboard.twbx`: The Tableau workbook containing the dashboard.

## How to Use
1. Download the Tableau workbook (`world_population_dashboard.twbx`).
2. Open the workbook in Tableau Desktop or Tableau Public.
3. Explore the dashboard to view insights on world population trends.
